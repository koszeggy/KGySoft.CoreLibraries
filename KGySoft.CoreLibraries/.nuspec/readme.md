KGy SOFT Core Libraries offer high-performance and handy general libraries.
Many of them aim to replace existing APIs of the original .NET framework with more efficient versions.

Among others:
- Useful [extensions](https://koszeggy.github.io/docs/corelibraries/html/N_KGySoft_CoreLibraries.htm) for simple types, collections, and others
- High-performance [collections](https://koszeggy.github.io/docs/corelibraries/html/N_KGySoft_Collections.htm)
- [Fast enum handling](https://koszeggy.github.io/docs/corelibraries/html/T_KGySoft_CoreLibraries_Enum_1.htm)
- High-performance [reflection API](https://koszeggy.github.io/docs/corelibraries/html/N_KGySoft_Reflection.htm)
- Very compact and efficient [binary serializer](https://koszeggy.github.io/docs/corelibraries/html/T_KGySoft_Serialization_Binary_BinarySerializationFormatter.htm) with safe mode
- Powerful [XML serializer](https://koszeggy.github.io/docs/corelibraries/html/T_KGySoft_Serialization_Xml_XmlSerializer.htm)
- [Resource managers](https://koszeggy.github.io/docs/corelibraries/html/N_KGySoft_Resources.htm) for .resx resources with dynamic expansion support
- [Base classes for business objects and model classes](https://koszeggy.github.io/docs/corelibraries/html/T_KGySoft_ComponentModel_ModelBase.htm) with change tracking, editing, undo/redo capability and validation.
- Technology-agnostic [command binding](https://koszeggy.github.io/docs/corelibraries/html/T_KGySoft_ComponentModel_ICommand.htm) with disposable event handlers
- Performance measurement and other [diagnostic tools](https://koszeggy.github.io/docs/corelibraries/html/N_KGySoft_Diagnostics.htm)
- and more...

See the [online help](https://koszeggy.github.io/docs/corelibraries) for the complete documentation or the [GitHub page](https://github.com/koszeggy/KGySoft.CoreLibraries) for some highlighted code examples.

See also this WPF/WinForms [demo application](https://github.com/koszeggy/KGySoft.ComponentModelDemo), which focuses mainly on some [KGySoft.ComponentModel](https://koszeggy.github.io/docs/corelibraries/html/N_KGySoft_ComponentModel.htm) features.
